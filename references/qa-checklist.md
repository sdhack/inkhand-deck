# QA Checklist · Fused Skill

> 版本 2.0.0 · 2026-08-28（墨仔 v2.0 形象升级 + 手写字体 + 嘴巴差异化 + 抖音竖版）

Run before delivery. Mark each item.

## Deck shell consistency

- [ ] Every page uses near-white warm paper `#FBFAF5` with subtle grain.
- [ ] Border convention consistent: no full-page border for PPT; thin double-line border + decorative corner flourishes for Douyin/social vertical.
- [ ] Every body page has a page number `NN / TT` in the upper-left (cover optional).
- [ ] Every body page title is centered, with one ink-black handdrawn wavy underline.
- [ ] Every page title optical size matches across body pages (short titles not enlarged).
- [ ] Corner construction marks present but very faint on every page.
- [ ] Large negative space preserved on every page.
- [ ] Pastel label palette consistent (pale blue / sage / peach / lavender).
- [ ] **ALL text is Chinese handwritten style** — no formal printed fonts, no English text.
- [ ] Title uses bold brush/marker hand-lettering; subtitles/labels use casual pencil handwriting.

## 墨仔 consistency (v2.0)

- [ ] 墨仔 is present on every body page.
- [ ] 墨仔 is **not** present as a corner decoration on busy pages (it's the actor).
- [ ] At most **one** 墨仔 per page.
- [ ] 墨仔 scale is 12–22% page height when active, ≤10% on takeaway/signature pages.
- [ ] **Body shape**: slim elongated teardrop, NOT chubby/round/spherical/fat.
- [ ] **Top of head**: rounded dome, NOT pointed/sharp/narrow tip.
- [ ] **Tendril**: thin curly tendril with spiral-shaped coil loop (NOT simple loop).
- [ ] **Leaves**: exactly TWO sage-green leaves above the spiral (NOT one, NOT three).
- [ ] **Eyes**: medium-sized round eyes (50-55% face width), NOT extremely large, NOT tiny white-dot eyes.
- [ ] **Eye whites**: large white eye whites.
- [ ] **Pupils**: small black pupils positioned in the UPPER part (looking upward), NOT centered.
- [ ] **Mouth**: small but clear and visible, NOT no mouth/invisible.
- [ ] **Mouth differentiation**: across a multi-page deck, at least 3 different mouth shapes are used (NOT the same shape on every page).
- [ ] **Arms**: exactly TWO thin black arms, always present (NOT missing, NOT extra).
- [ ] **Legs**: exactly TWO thin black legs, always present (NOT missing, NOT extra).
- [ ] **Body color**: soft matte ink-black (#1A1A1A, not pure #000000) with faint paper grain (not a hard silhouette).
- [ ] Optional tiny warm red-orange core dot may be present or omitted.
- [ ] 墨仔 has no clothing, no shiny eyes, no cute-mascot-overload big grin.
- [ ] 墨仔 is performing the core conceptual action on every body page.
- [ ] Spiral coil and two green leaves are visible in every appearance.

## Content accuracy

- [ ] Every page has one main point.
- [ ] Archetype varies across the deck (no three identical layouts in a row).
- [ ] Required text only lists match what's actually rendered.
- [ ] No fake English, URLs, or filler text on any prop.
- [ ] No invented micro-labels beyond the spec.
- [ ] **For Douyin/social vertical**: cover has a strong hook tied to current news hotspot.
- [ ] **For Douyin/social vertical**: text information density is sufficient (key data, tags, quote boxes).

## Diagram integrity

- [ ] Arrows, groupings, and flows come from linework, not from 墨仔.
- [ ] 墨仔 operates within the diagram; the diagram does not depend on 墨仔 for meaning that should be structural.
- [ ] Removing 墨仔 should weaken (not destroy) the metaphor — meaning the structure still reads, but the actor's presence makes it true.

## Hand-drawn detail quality

- [ ] Rich detail: cross-hatching, stippling, subtle ink bleed, delicate hatching.
- [ ] Fine handdrawn lines, stable but slightly irregular.
- [ ] No thick outlines, no vector-clean look, no corporate template feel.
- [ ] Wavy underlines for titles (not straight lines).

## Deliverable hygiene

- [ ] Final images saved into a workspace folder.
- [ ] Contact sheet generated for multi-page decks.
- [ ] Image dimensions reported (actual vs target).
- [ ] Watermark check: if present, crop reminder included for the user.
- [ ] File count verified == requested page count (no parallel-generation filename collisions).
- [ ] For social vertical: 3:4 ratio confirmed (1080x1440 or equivalent).
