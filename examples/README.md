# examples/

本目录存放 inkhand-deck 技能的实际产出示例（均为**本地 SVG 矢量 + 无头 Chrome 渲染**，无水印、不花 credits）。

## 胶原蛋白肽科普-墨蓝SVG-deck/
墨仔出镜的 9:16 竖版科普图文 7 页（胶原蛋白肽是不是智商税）：
- `01-封面.svg` ~ `07-落点.svg`：矢量源文件（可二次编辑）
- `01-封面.png` ~ `07-落点.png`：1080×1920 渲染图
- `contact-sheet-墨蓝SVG.png`：4×2 总览
- `_make_contact_sheet.py`：拼图脚本

## mozai/
