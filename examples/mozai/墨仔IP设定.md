# 墨仔（Mozai）· IP 设定 v0.1（初版墨黑）

> 版本 0.1 · 2026-08-27
> 初版设计。v1.0.0 曾改为墨蓝去黑，v1.1.0 恢复本初版墨黑。
> 权威源：`inkhand-deck` 技能 `references/mozai-character.md`。

## 一、是什么

墨仔是一滴在纸上活过来的墨。它是「系统操作员」，每页作为一个演员承担核心动作主体（搬运 / 漏斗 / 拉线 / 警示 / 记录 / 探头），不是角落装饰。

灵感来源：`ian-xiaohei-illustrations` 的「小黑」（黑色实心、白点眼、细腿、空表情）+ `ian-handdrawn-ppt` 的精致手绘外壳。融合形成原创 IP「墨仔」——比小黑更克制、更偏技术文档气质，比 handdrawn 多一个持续出场的主角。

## 二、形象规范

### 身体
- **形状**：软墨泪滴（上尖下圆），柔边、不规则
- **质感**：哑光，带轻微纸纹与墨晕（不是死黑硬剪影）
- **颜色**：墨黑 `#1A1A1A`（非死黑 `#000000`，保留轻微不均匀墨质）

### 签名件（每页必须保留）
- **顶部一根细卷须** + 末端**一片小绿芽 `#A3C9A8`**（签名标记，绝不可丢）
- **两个白点眼**（deadpan / 死鱼眼）
- **胸口一个红橙墨芯 `#E07B39`**（小、单）

### 肢体
- 两条细腿（默认）
- 细手臂仅在动作需要时出现（搬运 / 拿物 / 警示举牌 / 记录书写）
- 不穿衣服、不戴配件

## 三、初版配色锁（死规定）

| 件 | hex | 说明 |
|---|---|---|
| 身体 | `#1A1A1A` | 墨黑实心，非死黑 `#000000` |
| 线稿 | `#1A1A1A` | 与身体同墨黑，初版统一 |
| 绿芽 | `#A3C9A8` | sage green 签名 |
| 墨芯 | `#E07B39` | 暖红橙 单点 |
| 白点眼 | `#FFFFFF` | |
| 纸 | `#FBFAF5` | 暖白 |
| pastel 标签 | pale blue / sage / peach / lavender | 信息标签用，非墨仔本体 |

**HARD RULE**：身体与线稿均为墨黑 `#1A1A1A`，禁止死黑 `#000000`（保持墨质不均匀），禁止偏蓝（那是 v1.0.0 的墨蓝版，已 revert）。

## 四、姿态变体（动作库）

墨仔的身体是墨，可形变但保留软墨感 + 绿芽可见：

- **Rest**：泪滴身 + 两腿 + 芽上
- **Carry**：同身 + 两细臂持物件
- **Funnel**：身变墨黑漏斗（绿芽尽量保留，可能极小）
- **Pull**：身后倾 + 一臂拉线/绳
- **Warn**：身立 + 一臂举警示牌或指警告点
- **Record**：身坐 + 膝上小本 + 一臂书写
- **Open / Peek**：半出小洞/抽屉/机器，绿芽可见
- **Transform**：身变形为小机件（齿轮/杆/杠），仍软墨，芽可见
- **Tiny corner**：仅 takeaway/收尾页用 ≤8% 页面高，否则墨仔必须当演员

## 五、性格（必须读出）

- 死板、冷静、专注手头活
- 有点笨拙但不蠢
- 荒诞感来自"它做的事 = 隐喻本身"
- 冷幽默，绝不卖萌、绝不闪光眼、绝不咧嘴笑

## 六、比例锁

- 活跃墨仔：**12–22% 页面高**
- 签名/收尾小墨仔：≤8% 页面高
- 不压标题、不碰页码、不遮角落记号
- 永远不要撑满一页

## 七、每页一条铁律

- **EXACTLY ONE** 墨仔（每页 1 个，不多不少）
- 绿芽签名每页可见
- 细白点眼 + deadpan 脸
- 不穿衣服、不持"穿"的物件（可手持）

## 八、与墨蓝版（v1.0.0）的差异

v1.0.0 改墨蓝去黑（body `#23386B` / line `#34465E`，绝不用纯黑），v1.1.0 revert 回初版：

| | 初版墨黑（本设定） | v1.0.0 墨蓝去黑 |
|---|---|---|
| body | `#1A1A1A` 墨黑 | `#23386B` 墨蓝 |
| line | `#1A1A1A` 墨黑 | `#34465E` 深蓝灰 |
| 绿芽 / 墨芯 / 白点眼 / 纸 | 保留 | 保留 |
| 标题下划线 | 墨黑 | pale blue |
| HARD RULE | 非死黑 `#000000`，不偏蓝 | 绝不用纯黑 |

两套可并存（墨蓝 deck 已交付，作为历史对比存档）；当前**默认 = 初版墨黑**。

## 九、禁忌

- 可爱吉祥物 / 大眼闪光 / 咧嘴笑 / chibi 比例
- 给墨仔穿衣服或戴配件
- 一页多个墨仔
- 墨仔缩角落当看客（正文页它是演员）
- 死黑 `#000000` 平涂（必须留墨质）
- 用墨仔替代图表结构（它在结构里"操作"，不"变成"结构）
- 偏蓝、偏紫、偏任何非墨黑/签名件的色（v1.0.0 残留，已 revert）
